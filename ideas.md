# VerifAI — Existing Product Design Direction

## Ground truth
This is an existing VerifAI procurement-compliance workspace. Preserve its name, current information architecture, accepted components, and white / institutional-blue / orange palette. This implementation is an additive extension of the current design, not a redesign or a new brand.

## Design dimensions
- **Movement:** Quiet enterprise software for public procurement: precise, accountable, restrained, and legible rather than promotional.
- **Principles:** Put source traceability before automation claims; separate evidence from interpretation; make uncertainty visible; keep officer decisions explicit; use consistent organization-scoped views.
- **Color philosophy:** Reuse the existing CSS tokens. Institutional blue (`#1565c0`, deep navy `#0d2b45`) anchors navigation and action; orange (`#f59e0b`) flags review/attention; green and red remain reserved for verified and adverse outcomes; pale neutral surfaces preserve reading contrast.
- **Layout paradigm:** Retain the fixed dark-blue workspace rail, white top bar, responsive content canvas, compact operational cards, and evidence tables. Keep the existing page and modal navigation.
- **Signature elements:** VerifAI shield mark, thin blue/orange emphasis, clear demo ribbon, status badges, concise source rows, and an ordered PROVE IT evidence chain that exposes each link instead of introducing a competing visual concept.
- **Interaction philosophy:** Direct and auditable. Opening proof should reveal the actual persisted record, both sides of any conflict, the source’s sandbox state, the applied rule, and the result. External-source unavailability stays visibly pending, not punitive.
- **Animation:** Keep existing short hover/transition and loading-spinner behaviors. No new decorative motion.
- **Typography system:** Retain the current Inter / IBM Plex Sans / system sans-serif stack, existing compact table scale, and strong heading hierarchy.
- **Brand essence:** Evidence-backed procurement decisions that an officer can explain and review.
- **Brand voice:** Formal, plain, factual, and explicit about what is demo data, sandbox output, and human judgment.
- **Wordmark/logo:** Preserve the existing VerifAI shield wordmark and favicon; do not generate or substitute new brand assets.
- **Signature brand color:** Existing VerifAI institutional blue, balanced with the already-defined orange review accent.
